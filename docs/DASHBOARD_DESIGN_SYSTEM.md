# Timber Dashboard Design System & Integration Specification

> **See Root Document:** The full authoritative specification is available at [DASHBOARD_DESIGN_SYSTEM.md](../DASHBOARD_DESIGN_SYSTEM.md).

## Quick Summary for Integration
- **Layout:** Apple-inspired Floating Glassmorphic Topbar + Left Dock Sidebar (macOS magnification engine) + Solid Brand Hero Banner with 5 Embedded Glass KPI Cards + 2-Column Bento Grid (`1fr 360px`).
- **Brand Agnostic Architecture:** Pure CSS variables (`--color-primary`, `--color-primary-hover`, `--color-supporting`, `--color-pale`). Adapts to any host system's primary colors in seconds.
- **Tokens & Recipes:** Includes pre-computed palettes for Corporate Blue, Modern Violet/Purple, Minimalist Charcoal, and Ruby Crimson.
- **Compliance:** Full WCAG 2.1 AA/AAA light mode contrast standards and zero-emoji Lucide/Heroicons SVG rules.

Please review [DASHBOARD_DESIGN_SYSTEM.md](../DASHBOARD_DESIGN_SYSTEM.md) for full wireframes, component HTML/JSX code snippets, dock physics math, and step-by-step integration guide.
